# Task 2 – Logo Design

## Project Overview

A logo design project focused on developing a distinctive visual identity for a fictional café brand, The Second Home Café.

## Task

Create a memorable logo that communicates the brand's concept, personality, and visual direction.

## Deliverables

- Primary Logo
- Light/Dark Logo Versions
- Final exported logo assets

## Tools Used

- Adobe Illustrator

##Assets
Google

## Design Approach

The identity combines a home-inspired form with botanical elements to communicate warmth, nature, comfort, and a welcoming sense of belonging.

## Brand

The Second Home Café
