# Task 5 – Multi-Page Magazine Layout

## Project Overview

A multi-page editorial design created as part of the OIBSIP Graphic Design Internship, demonstrating principles of print design, typography, grid systems, image placement, visual hierarchy, and consistent page composition.

## Objective

The objective was to create a multi-page magazine layout with a consistent visual language across different pages while maintaining readability, structure, and an engaging editorial presentation.

## Design Approach

The layout uses a consistent grid, typography system, colour palette, imagery, page structure, and recurring visual elements to create a cohesive editorial experience.

Different page compositions were developed while maintaining consistency in spacing, hierarchy, typography, and overall visual direction.
