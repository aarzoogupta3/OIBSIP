# Task 5 – Multi-Page Magazine Layout

## Project Overview

A multi-page editorial layout created as part of a graphic design assignment, demonstrating principles of print design, typography, grid systems, image placement, and visual hierarchy.

## Task

Create a multi-page magazine or brochure layout for a fictional or existing brand while maintaining consistency across pages.

## Deliverable
